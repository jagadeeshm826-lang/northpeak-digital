# 🚀 NorthPeak Digital

A modern, responsive one-page digital agency website built as part of the **Digital Heroes Internship Task A & Task B**.

## 📌 Project Overview

NorthPeak Digital is a fictional digital agency that helps businesses grow through innovative web development, branding, SEO, UI/UX design, cloud solutions, and digital marketing.

This project demonstrates responsive web design, modern UI principles, accessibility best practices, and performance optimization.

---

## ✨ Features

- 🎯 Hero section with Call-to-Action
- 💻 Services section (6 services)
- ⭐ Client Results / Testimonials
- 💰 Pricing Plans (3 tiers)
- 📩 Contact Form with Client-side Validation
- 📱 Fully Responsive Design
- 🎨 Modern UI with Animations
- ♿ Accessibility Improvements
- ⚡ Performance Optimizations
- 🔍 SEO Friendly Structure
